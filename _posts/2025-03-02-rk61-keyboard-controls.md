### Regular Functions

|Function|Combination|
-|-
|Switch to Windows keyboard mode|`Fn + A`|
|Switch to Mac keyboard mode|`Fn + S`|
|Lock Win-key| `Fn + Win` |
|Switch to device 1 | `Fn + Q` |
|Switch to device 2 | `Fn + W` |
|Switch to device 3 | `Fn + E` |
|Directional Key Toggle| `Fn + :Enter:`|

> **NOTE:** To begin Bluetooth pairing, hold down the device key for 3-5 seconds
  e.g. `Fn + Q`

### RGB Functions

|Function|Combination|
-|-
|Switch lighting patterns|`Fn + \`|
|Increase light brightness|`Fn + ]`|
|Decrease light brightness|`Fn + [`|
|Increase light changing speed|`Fn + '`|
|Decrease light changing speed|`Fn + ;`|
|Change RGB Color|`Fn + .`|

## States

Pressing `Fn + LCtrl` cycles the keyboard between three different states. There are no indicators to show which state you are currently in.

|State|Description|
-|-
|State 1|Basic keyboard functions and numbers take precedence|
|State 2|Function keys and alternate functions take precedence|
|State 3|Function keys take precedence over numbers|
